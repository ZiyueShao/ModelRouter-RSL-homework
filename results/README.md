## 保留的失败与改进

旧版本测试只有1/8正确，且没有成功修订出经验。新开发试验先增加训练字段反馈、修订历史和逐行输入；训练标签能帮助改对，但前两条候选经验都未通过验证。这一开发试验在训练阶段停止，没有运行新测试集。

随后允许列计算过程，最终JSON做可追溯提取。训练阶段发现旧提取规则会误拒绝计算说明中单个反引号标记的字段名，修复并补充测试后重新冻结方案、从空经验重跑。两次开发试验都未进入新测试集。规范化只去掉外部说明及明确的代码围栏，不更改字段、排序、数值或检查标准；多个代码块、JSON后多余文字、重复字段仍拒绝。

`diagnostics.json` 保存旧实验与中途停止的开发记录。旧8题已看过，新测试使用另外20题；不能把旧12.5%与新结果作同题提升比较。各组使用相同的新提示和检查器，因此当前组间比较衡量的是反馈或经验的额外作用。

## 文件

- `learning.json`：每次训练、候选规则、验证前后原始回答。
- `evaluation.json`：20道新测试题的三个对照组、原始输出、规范化结果及耗时。
- `environment.json`：模型摘要、运行设置、代码摘要、预热和租用记录。
- `verification.json`：独立重算标准答案，检查评分、最好答案、验证接纳条件与测试期间经验冻结。
- `diagnostics.json`：历史失败记录，避免只保留好结果。

云端机器已终止，费用估算见 `environment.json` 的 `rental`；该值按公开小时价和租用时间估算，不是账户结算账单。所有实验中的接口故障与未完成记录均不计为成功。
